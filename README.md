# Follow-Up Ladder Builder

Builds the engaged-lead cadence: same-day first touch, +2d goodwill bump, +5d magnet bump, then weekly consented nurture — every bump carries an asset, never a bare check-in.

A free plugin from KAIROS AI Systems — one focused tool that does one job well for a
small business: no suite to learn, no setup project, no account required beyond your
agent host.

## What it does

Engaged = opted in, replied, booked, or attended; nurture never runs on cold lists. Blocked threads are held, never re-fired into a block.

## How to use it

Add this plugin to a compatible agent host (Cursor, Grok Bot, or another
agent-plugins host), then ask in plain language, for example:

> Use the Follow-Up Ladder Builder to help me: builds the engaged-lead cadence: same-day first touch, +2d goodwill bump, +5d magnet bump, then weekly consented nurture — every bump carries an asset, never a bare check-in — I'll paste the details.

The plugin works from the facts you give it — your services, your prices, your
records. It never invents a number, a policy, or a result; anything it projects is
labelled an estimate with its basis. Drafts that would go to a customer stay drafts
until you approve them.
